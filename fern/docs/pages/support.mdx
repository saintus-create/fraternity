### Filing a useful issue

<Steps>
  <Step title="Pick the right repository">
    Use the docs-starter repository for problems with this template, and the Fern repository for platform bugs and feature requests.
  </Step>
  <Step title="Search existing issues">
    Check whether someone has already reported the same problem before opening a new issue.
  </Step>
  <Step title="Describe what you expected and what happened">
    Include the page or configuration involved and steps to reproduce so the team can act on it quickly.
  </Step>
</Steps>
